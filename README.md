# Cave Adventure

A simple text-based adventure game written in Python, built as a learning project.

## How to play

1. Make sure you have Python 3 installed.
2. Run the game:
   ```
   python cave_adventure.py
   ```
3. Follow the prompts, type the number of your choice, and press Enter.

## What it teaches

- Variables and dictionaries (tracking player state)
- Functions (each room is its own function)
- Conditionals (`if` / `elif` / `else`)
- User input with `input()`

## Ideas to extend it

- Add more rooms and choices
- Add an inventory system with multiple items
- Add a scoring system
- Rewrite the flow using a `while True` loop so you can retry without rerunning the script
